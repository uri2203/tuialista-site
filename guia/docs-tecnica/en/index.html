1 What this agent does

You point it at the project folder and it:

  • Scans the code and extracts its structure (functions, classes, comments, imports).
  • Generates a professional README for the project (structure, components, dependencies, usage).
  • Documents a specific file in detail (purpose, functions, parameters, notes).
  • Generates a technical FAQ with questions and answers based on the code.
  • Detects undocumented functions and classes.
  • Builds a dependency map between files (internal and external).
  • Answers free-form questions about the code.

Supports many languages: Python, JavaScript/TypeScript, Java, Kotlin, C/C++, Go, PHP, Ruby, SQL, and even RPG (AS/400/IBM i) and COBOL, among others.

3 How to use it

The agent opens a chat window, like a messaging app — not a programmer's black screen. You type your command or question in the text box below, hit Send (or Enter), and the reply appears as a message, just like in this real image:

The commands below are the words you can type in that same text box:

> readme

A professional README.md with name, structure, main components, how they relate, dependencies and usage instructions.

> faq

8 to 12 technical FAQs (architecture, how something works, how to change functionality...) with answers based on your code.

> document <file>

Detailed documentation for a file: purpose, each function/procedure (what it does, parameters, return value), dependencies and notes.

> undocumented

Functions and classes with no comments or docstring, with file and line number.

> dependencies

Dependency map: per file, which internal project modules and external libraries it uses.

> analyze <file>

The detected structure of a file (classes, functions with their line number, imports) without calling AI.

> free-form question?

Type any question in natural language, e.g.: where is the session token validated?

> exit

Ends the session (exit also works).

5 Frequently asked questions

Does my code get uploaded to the internet?
No. The scan and structure analysis are local (see Privacy, section 7).
What languages does it support?
Python, JavaScript/TypeScript, Java, Kotlin, Scala, C/C++, Go, PHP, Ruby, Rust, Swift, C#, VB, SQL, RPG (AS/400), COBOL, shell, PowerShell and more, plus text/config files (Markdown, JSON, YAML, XML, HTML/CSS...).
Do I need to install extra libraries?
No. Unlike other agents, this one reads files as text; it only needs the SDK's base dependencies.
Does it skip folders like node_modules?
Yes. It ignores node_modules, .git, __pycache__, venv, .venv, dist, build, target, .idea, .vscode, caches, etc.
Does it modify my code or write files?
No. It generates the documentation as on-screen text; you decide where to save it. The agent doesn't touch your files.
How large can the project be?
It scans the whole tree, but to generate README/FAQ/document it uses an extract of the code (the most relevant files and fragments) to fit within the AI's context.
Does it work for AS/400 code (RPG/COBOL)?
Yes. It extracts subroutines, procedures and paragraphs, and the documentation uses IBM i terminology where appropriate.
What language does it reply in?
Whatever language you write to it in.
Is the documentation 100% accurate?
It's an excellent AI-generated starting point based on your code; review it before publishing, especially for critical details.
Can I document a single file without scanning everything?
On startup it scans the project once; after that you can work on specific files with document and analyze.

6 Troubleshooting

It shows “0 files indexed”
The folder is empty, the path is wrong, or it only has unsupported file types. Check that you chose the right folder when activating the agent.
It can't find a file with document/analyze
Use the relative path exactly as it appears in the scan, or just the file name (the search is flexible).
The README skips some files
To fit within the AI's context, the README summarizes the main components; use document <file> for the detail of a specific one.
It says “Invalid license” or asks to reconnect
Check that the key you pasted is correct (no extra spaces), make sure you have internet the first time you activate, and if you've been offline for more than 3 days, reconnect once to revalidate.
“No AI providers configured”
readme, faq, document and free-form questions use AI — if the engine isn't configured, contact support. undocumented, dependencies and analyze still work locally, without AI.

None of these fixed your problem? Write to us directly — we'll gladly look into it with you.

7 Privacy and confidentiality

Your source code never leaves your computer.

  • The agent scans the project and extracts its structure locally, on your own machine. It doesn't upload your code to any server.
  • Structure detection, documentation debt (undocumented) and the dependency map are all calculated on your machine.
  • The only thing that travels over the internet is: (1) a check that your license is active — which doesn't include your code —, and (2) when generating a README, FAQ, documenting a file or answering a question, code fragments (the most relevant ones) are sent to the AI engine to draft the text.
The confidentiality of your intellectual property is guaranteed by design: undocumented, dependencies and analyze are 100% local. Only readme, faq, document and free-form questions share code fragments with the AI provider.
Important reminder: the generated documentation is an excellent starting point, not a flawless final document. The agent describes what it finds in the code; it can misread very complex logic or infer the wrong purpose. Review the documentation before publishing it, especially on critical projects.
