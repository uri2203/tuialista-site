1 What this agent does

You point it at your sheets and ask anything, in your own words:

  • “get the total by region and make me the chart”
  • “create a sheet with these columns and link it to the other file”
  • “executive report with formatting, a pivot table and an embedded chart”

3 How to use it

The agent opens a chat window, like a messaging app — not a programmer's black screen. There are no commands to memorize: you ask for what you need the way you'd ask an analyst, hit Send (or Enter), and it gets done:

What it does WITHOUT needing AI (safe mode, on by default)

  • Reconcile 2 files / detect what's missing
  • Consolidate several files into one · remove duplicates · clean up
  • Accounts receivable aging (30/60/90)
  • Inventory: below minimum · valuation · dead stock
  • Cross-reference and pull data (VLOOKUP) · pivot tables · top-N · totals by X
  • Compare prices/versions · cheapest quote · detect anomalies
  • Cash flow · budget vs actual · VAT · time-clock hours
Safe mode vs. expert mode: by default the agent only uses these 100%-tested tasks — zero risk to your data. If you type “expert mode”, it also tries new requests with AI (isolated, it can never touch or damage your files). Go back with “safe mode”.

5 Frequently asked questions

Does my data get uploaded to the internet?
No. Everything is processed on your computer (see Privacy, section 7).
What formats does it accept?
Excel (.xlsx) and CSV (.csv), including subfolders. Old .xls files are best saved as .xlsx.
Does it really execute the operation, or just describe it?
It executes it. The agent builds the operation, runs it in a secure local sandbox (isolated, with no access to the rest of your system), and hands you the table on screen and the finished file — it's not a simulation.
What happens if I ask for something outside the tested recipes?
In safe mode (the default) it tells you what it can actually do. If you turn on “expert mode”, it tries to solve it with AI in isolation — it can never damage your original files.
Can live mode damage my open Excel file?
Reads are immediate and safe. Writes always show you a preview first and are only applied if you confirm with “yes”.
What language does it reply in?
Whatever language you write to it in.
Can it read several files at once?
Yes. It loads every .xlsx and .csv in the folder and can combine them (lookups, reconciliations, consolidations).
Can I change the data folder?
Yes. Reopen the agent and click “Choose…” to change it (if it doesn't ask, delete config.json inside %USERPROFILE%\.tuialista).
Does it modify my original files?
Recipes and reports create new files by default. Live mode does write to the open file, but only after your explicit confirmation.
What are “routines”?
Operations you record once (“save this as my...”) to repeat later with a single request (“run my...”), instead of explaining everything again each time.

6 Troubleshooting

It won't load an Excel file
Make sure the file is a valid .xlsx (not an old .xls or a corrupted file).
It shows “0 sheets loaded”
The folder is empty or the path is wrong. Check that you chose the right folder when activating the agent.
It says “Invalid license” or asks to reconnect
Check that the key you pasted is correct (no extra spaces), make sure you have internet the first time you activate, and if you've been offline for more than 3 days, reconnect once to revalidate.
It says that task isn't in safe mode
That's expected: in safe mode it only runs 100%-tested tasks. Say “expert mode” to have it try solving it with AI (isolated, no risk to your files), or rephrase your request to match one of the recipes in section 3.
Live mode isn't responding
Confirm the file is actually open in Excel at that moment — live mode works on the Excel you already have on screen, not on closed files.

7 Privacy and confidentiality

Your data never leaves your computer.

  • The automatic recipes (reconcile, consolidate, accounts receivable, inventory, pull data from another table, pivot tables, cash flow...) run 100% locally, no AI.
  • For new AI-handled tasks (expert mode), the AI only receives the structure (column names), never your data.
  • The only things that travel over the internet are: (1) a check that your license is active, and (2) the structure of your sheets when AI is needed for a new task.
The sandbox where generated code runs is local — never on an external server. Your figures, amounts, and customer data never leave your machine at any point in the process.
Important reminder: this agent is an analysis-support tool, not a substitute for your judgment. Tested recipes are reliable; for new tasks solved with AI, verify critical figures in your original file before making important decisions based on them.
