Was löst er und was brauchen Sie?

Jedes Unternehmen hat Ordner voller Verträge, Handbücher, Akten, Richtlinien und Berichte... und wenn jemand eine Information braucht, muss er Datei für Datei öffnen, bis er sie findet. Dieser Agent liest alles und beantwortet Ihre Frage direkt, unter genauer Angabe der Datei, aus der die Information stammt.

1 Was dieser Agent tut

Es ist der einfachste Agent im Katalog. Sie zeigen ihm den Ordner, in dem Sie Ihre Dokumente aufbewahren, und er:

  • Liest sie alle (PDF, Word, Text und Markdown), ohne dass Sie sie einzeln öffnen müssen.
  • Beantwortet Ihre Fragen in normaler Sprache: “was sagt das Handbuch über Urlaub?”
  • Zitiert die Datei, aus der er jede Information genommen hat, damit Sie sie überprüfen können.
  • Wenn die Antwort nicht in Ihren Dokumenten steht, sagt er es Ihnen, anstatt sie zu erfinden.

Ergebnis: Sie finden jede Information in Sekunden, ohne sich zu erinnern, in welcher Datei sie war.

2 Installation (2 Minuten)

Für Windows. Keine dauerhafte Internetverbindung nötig, nichts wird in die Cloud hochgeladen.

1
Herunterladen und installieren

Laden Sie das Installationsprogramm von tuialista.com/descargar herunter (Dokumenten-Agent) und öffnen Sie es. Es erstellt eine Verknüpfung mit dem Logo auf Ihrem Desktop — kein Python oder Terminal erforderlich.

2
Öffnen Sie es vom Desktop aus

Doppelklicken Sie auf das neue Symbol. Fügen Sie Ihren Lizenzschlüssel ein (er wurde Ihnen beim Kauf per E-Mail zugesandt) und klicken Sie auf Aktivieren. Sie sehen ein grünes Häkchen, wenn er gültig ist.

3
Wählen Sie Ihren Ordner

Wählen Sie den Ordner mit Ihren Dokumenten aus und klicken Sie auf Agent jetzt verwenden. Beim nächsten Mal startet er direkt — er merkt sich Ihren Schlüssel und Ihren Ordner.

3 So verwenden Sie ihn

Der Agent öffnet ein Chat-Fenster, wie eine Messaging-App — kein schwarzer Programmierer-Bildschirm. Dies ist der direkteste Agent im Katalog: keine Befehle zum Auswendiglernen. Sie schreiben Ihre Frage mit eigenen Worten in das Textfeld unten, klicken auf Senden (oder Enter), und der Agent sucht die Antwort in Ihren Dokumenten:

Wenn kein Dokument die Information enthält, sagt Ihnen der Agent dies klar, statt eine Antwort zu erfinden — das erspart Ihnen vergebliches Weitersuchen. Schreiben Sie beenden (oder exit), um zu beenden.

Der Agent indiziert den Ordner beim Start. Wenn Sie neue Dokumente hinzufügen, schließen Sie ihn und starten Sie ihn neu, damit er sie liest.

5 Häufig gestellte Fragen

Werden meine Dokumente ins Internet hochgeladen?
Nein. Alles wird auf Ihrem Computer verarbeitet (siehe Datenschutz, Abschnitt 7).
Brauche ich Internet, um ihn zu verwenden?
Nur für zwei Dinge: Ihre Lizenz zu validieren (bis zu 3 Tage offline) und die Antworten mit KI zu generieren. Das Lesen und Indizieren Ihrer Dokumente erfolgt auf Ihrem Gerät.
Welche Dateiformate akzeptiert er?
PDF, Word (.docx), Text (.txt) und Markdown (.md). Er sucht sie auch in Unterordnern.
Kann er ein gescanntes PDF lesen?
Nicht zuverlässig. Funktioniert besser mit PDF, das echten auswählbaren Text enthält.
In welcher Sprache antwortet er mir?
In der Sprache, in der Sie ihm schreiben.
Wie viele Dokumente kann er handhaben?
Es gibt kein festes Limit; er handhabt bequem Ordner mit Dutzenden von Dokumenten.
Sind die Antworten 100 % exakt?
Er ist sehr nützlich, kann aber bei langen oder ungewöhnlich formatierten Dokumenten eine Nuance auslassen. Verwenden Sie ihn als Leitfaden und überprüfen Sie das Kritische im Originaldokument, das er Ihnen zitiert.
Kann ich den Dokumentenordner ändern?
Ja. Öffnen Sie den Agenten erneut und klicken Sie auf “Auswählen…”, um ihn zu ändern (falls er nicht danach fragt, löschen Sie config.json in %USERPROFILE%\.tuialista).
Speichert er einen Verlauf meiner Fragen?
Er behält den Gesprächskontext, solange er geöffnet ist, um Folgefragen zu verstehen. Beim Schließen geht dieser Speicher verloren.
Ersetzt er eine Suchmaschine oder ein Dokumentenmanagementsystem?
Es ist eine Ergänzung: er versteht Fragen in natürlicher Sprache und gibt Ihnen die Antwort, nicht nur eine Liste von Dateien.

6 Problemlösung

Ein PDF wird nicht gelesen / zeigt “PDF nicht gelesen”
Das PDF ist wahrscheinlich ein gescanntes Bild ohne echten Text. Versuchen Sie eine Version mit auswählbarem Text.
Zeigt “Lizenz ungültig” oder fordert erneute Verbindung
Überprüfen Sie, ob der eingefügte Schlüssel korrekt ist (ohne zusätzliche Leerzeichen), stellen Sie sicher, dass Sie beim ersten Aktivieren Internet haben, und wenn Sie mehr als 3 Tage offline waren, verbinden Sie sich einmal erneut zur Neuvalidierung.
“Keine KI-Anbieter konfiguriert” beim Fragen
Die Antworten verwenden KI. Sehen Sie diese Meldung, fehlt die Konfiguration der KI-Engine; kontaktieren Sie den Support.
Zeigt “0 indizierte Dokumente”
Der Ordner ist leer oder der Pfad ist falsch. Überprüfen Sie, ob Sie beim Aktivieren des Agenten den richtigen Ordner ausgewählt haben.

7 Datenschutz und Vertraulichkeit

Ihre Dokumente verlassen nie Ihren Computer.

  • Der Agent liest und indiziert die Dateien lokal, auf Ihrem eigenen Gerät. Er lädt sie auf keinen Server hoch und teilt sie mit niemandem.
  • Die Suche und Auswahl der relevanten Fragmente erfolgt auf Ihrem Gerät.
  • Das Einzige, was über das Internet läuft, ist: (1) eine Überprüfung, dass Ihre Lizenz aktiv ist — die den Inhalt Ihrer Dokumente nicht enthält —, und (2) bei einer Frage wird ein Ausschnitt der relevanten Dokumente an die KI-Engine gesendet, um die Antwort zu verfassen.
Die Vertraulichkeit Ihrer Information ist durch Design garantiert: das Produkt entstand genau dafür, dass Sie Ihre Dokumente abfragen können, ohne sie offenzulegen. Jede Frage teilt nur das relevante Fragment mit dem KI-Anbieter — nie den vollständigen Ordner.
Wichtiger Hinweis: Dieser Agent ist ein Hilfsmittel, um Informationen schneller zu finden. Wie jedes KI-Tool können seine Antworten Ungenauigkeiten enthalten: überprüfen Sie immer kritische Daten im Originaldokument, das der Agent Ihnen zitiert, bevor Sie darauf basierende Entscheidungen treffen.
