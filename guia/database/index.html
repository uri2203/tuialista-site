1 Qué hace este agente

Tú le dices a qué base de datos conectarse y luego le preguntas en lenguaje normal:

  • Traduce tu pregunta a una consulta SELECT (solo lectura) y la ejecuta.
  • Te muestra la consulta SQL que generó y el resultado.
  • Nunca ejecuta operaciones que modifiquen datos (INSERT, UPDATE, DELETE, DROP...): un validador de seguridad bloquea cualquier consulta que no sea de lectura.
  • Funciona con SQLite, PostgreSQL y MySQL (SQLite viene listo; MySQL y PostgreSQL requieren instalar su extra).

El resultado: cualquier persona autorizada puede consultar los datos sin depender de que TI escriba la consulta, y sin riesgo de dañar nada.

2 Instalación

Para Windows. Este agente tiene un paso extra respecto a los agentes que leen carpetas: la conexión a tu base de datos se configura aparte.

1
Descárgalo e instálalo

Baja el instalador desde tuialista.com/descargar (agente Base de Datos) y ábrelo. Crea un acceso directo en tu escritorio con el logo — no requiere Python ni terminal.

2
Ábrelo desde el escritorio y activa tu licencia

Doble clic al ícono nuevo. Pega tu clave de licencia (te llegó por correo al comprar) y pulsa Activar. A diferencia de otros agentes, no te pide elegir una carpeta — este agente se conecta a una base de datos, no a archivos locales.

3
Configura la conexión (paso técnico)

Define las variables de entorno TARGET_DB_TYPE (sqlite, postgres o mysql) y TARGET_DB_URL con los datos de tu base. Para SQLite solo necesitas la ruta al archivo .db. Este paso lo hace normalmente el área de TI.

No tiene comandos que memorizar: le escribes tu pregunta en lenguaje normal en el cuadro de texto de abajo, pulsas Enviar (o Enter), y el agente genera la consulta, la ejecuta y te muestra el SQL, las columnas y los resultados:

Si tu pregunta se traduce en algo que modificaría datos, el agente lo rechaza: [Solo se permiten consultas de lectura (SELECT).]

El agente le entrega a la IA el esquema de tus tablas (nombres de tablas y columnas) para construir la consulta correcta. Los datos solo se leen cuando la consulta SELECT se ejecuta, y se limita a un máximo de 100 filas por respuesta. Escribe salir (o exit) para terminar.

5 Preguntas frecuentes

¿Puede dañar o borrar mis datos?
No. Opera en modo solo lectura. Un validador bloquea cualquier consulta que no empiece con SELECT o que contenga operaciones de escritura (INSERT, UPDATE, DELETE, DROP, ALTER, TRUNCATE, etc.) o varias sentencias.
¿Qué bases de datos soporta?
SQLite (incluido, sin extras), MySQL/MariaDB y PostgreSQL (requieren instalar su extra). Para SQLite solo necesitas la ruta al archivo .db.
¿Mis datos se suben a internet?
No. La conexión y la ejecución de consultas ocurren en tu equipo o tu red. A la IA solo se le envía el esquema (estructura de tablas) y tu pregunta; los datos que devuelve la consulta no se envían al motor de IA.
¿Necesito internet para usarlo?
Solo para validar tu licencia (hasta 3 días sin conexión) y para que la IA traduzca tu pregunta a SQL. La conexión a tu base de datos es local.
¿Por qué me muestra el SQL que generó?
Para transparencia: puedes revisar la consulta antes de confiar en el resultado, y aprender cómo se traduce tu pregunta.
¿Cuántos resultados devuelve?
Hasta 100 filas por consulta, como límite de seguridad.
¿En qué idioma me responde?
En el idioma en que le escribas.
¿Qué pasa si el agente genera un SQL incorrecto?
Puede ocurrir con esquemas complejos o nombres ambiguos. Revisa el SQL mostrado; si no es correcto, reformula tu pregunta siendo más específico.
¿Puedo cambiar de base de datos?
Sí. Cambia TARGET_DB_TYPE y TARGET_DB_URL y vuelve a arrancar el agente.
¿Necesita un usuario especial de base de datos?
Se recomienda conectarlo con un usuario de solo lectura de tu base de datos, como capa adicional de seguridad además del validador del agente.

6 Solución de problemas

“Tipo de BD no soportado”
Revisa TARGET_DB_TYPE. Valores válidos: sqlite, postgres (o postgresql), mysql.
Error al conectar a MySQL o PostgreSQL
Verifica el TARGET_DB_URL (host, puerto, usuario, contraseña, base) y que la base acepte conexiones desde tu equipo. Si acabas de cambiar de motor, contacta a soporte — puede que falte el extra de ese motor.
SQLite: “unable to open database file”
La ruta en TARGET_DB_URL es incorrecta o la carpeta no existe. Usa la ruta completa al archivo .db.
“Solo se permiten consultas de lectura (SELECT)”
Es el comportamiento esperado: pediste algo que modificaría datos. El agente solo hace consultas de lectura.
Dice “Licencia no válida” o pide reconectar
Revisa que la clave pegada sea correcta (sin espacios de más), confirma que tienes internet la primera vez que activas, y si estuviste más de 3 días sin conexión, reconéctate una vez para revalidar.
“No hay proveedores de IA configurados”
La traducción de la pregunta a SQL usa IA. Si ves este mensaje, falta configurar el motor de IA; contacta a soporte.

7 Privacidad y confidencialidad

Tu base de datos y sus datos nunca salen de tu infraestructura.

  • El agente se conecta a tu base de datos localmente (en tu equipo o tu red) y ejecuta las consultas ahí. Los resultados no se suben a ningún servidor.
  • A la IA solo se le envía el esquema (nombres de tablas y columnas) y tu pregunta, para redactar la consulta SELECT. Los datos que devuelve la consulta no se transmiten al motor de IA.
  • Lo único que viaja por internet es: (1) una comprobación de que tu licencia está activa, y (2) el esquema + tu pregunta para generar el SQL.
La confidencialidad de tus datos está garantizada por diseño, reforzada por el modo solo lectura: ningún dato real de una consulta llega al proveedor de IA, solo el esquema y tu pregunta.
Recordatorio importante: este agente consulta, no decide por ti. Es una herramienta de solo lectura que traduce tus preguntas a consultas SELECT. La generación de SQL por IA es muy útil, pero puede equivocarse con esquemas complejos: revisa la consulta mostrada y verifica los números críticos antes de tomar decisiones con ellos. Para máxima seguridad, conéctalo con un usuario de base de datos de solo lectura.
