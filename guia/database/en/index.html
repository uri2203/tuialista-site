1 What this agent does

You tell it which database to connect to, then ask it questions in plain language:

  • Translates your question into a SELECT query (read-only) and runs it.
  • Shows you the SQL query it generated and the result.
  • Never runs operations that modify data (INSERT, UPDATE, DELETE, DROP...): a security validator blocks any query that isn't read-only.
  • Works with SQLite, PostgreSQL and MySQL (SQLite works out of the box; MySQL and PostgreSQL require installing their extra).

The result: anyone authorized can query the data without depending on IT to write the query, and with no risk of damaging anything.

2 Installation

For Windows. This agent has one extra step compared to the folder-reading agents: the database connection is configured separately.

1
Download and install it

Download the installer from tuialista.com/descargar (Database agent) and open it. It creates a desktop shortcut with the logo — no Python or terminal needed.

2
Open it from your desktop and activate your license

Double-click the new icon. Paste your license key (you received it by email when you bought it) and click Activate. Unlike other agents, it won't ask you to choose a folder — this agent connects to a database, not to local files.

3
Configure the connection (technical step)

Set the environment variables TARGET_DB_TYPE (sqlite, postgres or mysql) and TARGET_DB_URL with your database's details. For SQLite you only need the path to the .db file. This step is usually done by the IT team.

5 Frequently asked questions

Can it damage or delete my data?
No. It operates in read-only mode. A validator blocks any query that doesn't start with SELECT, or that contains write operations (INSERT, UPDATE, DELETE, DROP, ALTER, TRUNCATE, etc.) or multiple statements.
What databases does it support?
SQLite (included, no extras), MySQL/MariaDB and PostgreSQL (require installing their extra). For SQLite you only need the path to the .db file.
Does my data get uploaded to the internet?
No. The connection and query execution happen on your machine or your network. Only the schema (table structure) and your question are sent to the AI; the data the query returns is never sent to the AI engine.
Do I need internet to use it?
Only to validate your license (works offline for up to 3 days) and for the AI to translate your question into SQL. The connection to your database is local.
Why does it show me the SQL it generated?
For transparency: you can review the query before trusting the result, and learn how your question gets translated.
How many results does it return?
Up to 100 rows per query, as a safety limit.
What language does it reply in?
Whatever language you write to it in.
What happens if the agent generates incorrect SQL?
It can happen with complex schemas or ambiguous names. Review the SQL shown; if it's not correct, rephrase your question to be more specific.
Can I switch databases?
Yes. Change TARGET_DB_TYPE and TARGET_DB_URL and restart the agent.
Does it need a special database user?
It's recommended to connect it with a read-only user of your database, as an extra security layer on top of the agent's validator.

6 Troubleshooting

“Unsupported DB type”
Check TARGET_DB_TYPE. Valid values: sqlite, postgres (or postgresql), mysql.
Error connecting to MySQL or PostgreSQL
Check the TARGET_DB_URL (host, port, user, password, database) and that the database accepts connections from your machine. If you just switched engines, contact support — that engine's extra may be missing.
SQLite: “unable to open database file”
The path in TARGET_DB_URL is wrong or the folder doesn't exist. Use the full path to the .db file.
“Only read queries (SELECT) are allowed”
This is expected behavior: you asked for something that would modify data. The agent only does read queries.
It says “Invalid license” or asks to reconnect
Check that the key you pasted is correct (no extra spaces), make sure you have internet the first time you activate, and if you've been offline for more than 3 days, reconnect once to revalidate.
“No AI providers configured”
Translating the question into SQL uses AI. If you see this message, the AI engine isn't configured; contact support.

7 Privacy and confidentiality

Your database and its data never leave your infrastructure.

  • The agent connects to your database locally (on your machine or your network) and runs queries there. Results aren't uploaded to any server.
  • Only the schema (table and column names) and your question are sent to the AI to draft the SELECT query. The data the query returns is never transmitted to the AI engine.
  • The only thing that travels over the internet is: (1) a check that your license is active, and (2) the schema + your question, to generate the SQL.
The confidentiality of your data is guaranteed by design, reinforced by read-only mode: no real query data ever reaches the AI provider, only the schema and your question.
Important reminder: this agent queries, it doesn't decide for you. It's a read-only tool that translates your questions into SELECT queries. AI-generated SQL is very useful, but it can be wrong on complex schemas: review the query shown and verify critical numbers before making decisions based on them. For maximum security, connect it with a read-only database user.
